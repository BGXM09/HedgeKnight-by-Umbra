# HedgeKnight Submission

## 50-word description

HedgeKnight turns a natural-language BNB protection request into a calculated, risk-checked, confirmed, monitored, and receipted simulated hedge. Built for Binance Agent OS, it coordinates source-labelled Binance evidence with deterministic exposure sizing, safety policy, expiring consent, simulated execution, and bounded reduce-only unwind—without selling the user's Spot BNB.

## 150-word description

HedgeKnight — by Umbra is a portfolio-protection agent for BNB holders. A user can say, “I hold 10 BNB. Hedge 50% of my exposure for 24 hours.” HedgeKnight normalizes the exposure, sizes a BNBUSDT perpetual short, estimates margin, fees, funding, and slippage, then evaluates an ordered deterministic risk policy. The user sees the complete before-and-after exposure and confirms one exact expiring plan before any simulated action occurs. The dashboard then shows the simulated fill, position, effective hedge ratio, PnL, evidence freshness, and a bounded reduce-only unwind. Every lifecycle produces canonical JSON with a verifiable SHA-256 digest. In an AI host, official Binance MCP supplies discoverable, source-labelled market and optional read-only account evidence while HedgeKnight MCP supplies protection intelligence. The public hackathon demo requires no credentials or funds and clearly distinguishes replay evidence from simulated financial actions. Live execution is unavailable.
